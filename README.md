# Hải Phát Vina

Mã nguồn WordPress theme dành cho Công ty TNHH Thương Mại Dịch Vụ Hải Phát Vina.

## Cấu trúc

- `hai-phat-vina/`: mã nguồn theme WordPress.
- `dev/`: công cụ kiểm thử local, xuất demo HTML và kiểm tra gói theme.

## Cài đặt

Đóng gói thư mục `hai-phat-vina` thành file ZIP, sau đó vào **WordPress → Giao diện → Thêm giao diện → Tải giao diện lên** để cài đặt.

Yêu cầu khuyến nghị: WordPress 6.4 trở lên và PHP 7.4 trở lên.
